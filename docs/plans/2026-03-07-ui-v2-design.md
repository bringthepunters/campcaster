# CampCaster UI v2 — Design Document

## Overview

Replace the current sidebar-based filter layout with a guided, header-first flow that naturally leads the user through the four decisions they need to make before results are meaningful: **when, where from, how far, what facilities**.

The existing UI remains on `main`. All v2 work lives on the `ui-v2` branch — rollback is `git checkout main`.

## Rollback Strategy

- Branch: `ui-v2`
- Rollback: `git checkout main`
- Files changed: `src/App.tsx`, `src/index.css`

## Layout

```
[ INCIDENT BANNER ]
[ GUIDED HEADER ]
  Step 1 — When?         Date from + Date to (inline, date to hidden until date from set)
  Step 2 — Where from?   Postcode/suburb autocomplete input
  Step 3 — How far?      Drive time slider with live label
[ FILTER CHIP BAR ]
  Facility chips: Dog-friendly, Toilets, Showers, BBQ, Fire pits, Drinking water, Vehicle access
  Weather chips: No heat (>33C), No rain  — disabled + grayed if date not in 14-day window
[ RESULTS HEADER ]
  N campsites found  +  List/Map toggle
[ RESULTS GRID ]  (full-width, 3-col on desktop, 1-col on mobile)
```

## Guided Header

### Step labels
Each step has:
- A small numbered label ("1 / WHEN")
- A contextual prompt that changes based on state
- Inline help/warning text

### Step 1 — When?
- Two date inputs side-by-side: "From" and "To (optional)"
- "To" input appears only after "From" is selected
- Inline note below: "Weather forecasts available for dates within the next 14 days."
- If selected date range is beyond 14 days: warm amber note "No forecast available — weather filters disabled"
- Prompt text: "Pick your dates and we'll check the weather and availability."

### Step 2 — Where from?
- Postcode or suburb input with datalist autocomplete
- Defaults to 3000 (Melbourne CBD) with placeholder "e.g. 3070 or Northcote"
- Prompt text: "We'll calculate drive times from here."
- Error shown inline in red if unrecognised location

### Step 3 — How far?
- Horizontal range slider, min 30min, max dynamic
- Live label shows formatted value: "Up to 2h 30m"
- Prompt text: "How long are you happy to drive?"

## Filter Chip Bar

Replaces the sidebar entirely. A horizontal wrapping row of pill-shaped toggle chips. Active chips are filled (fern green). Inactive are outlined.

Groups:
1. **Facilities** — Dog-friendly, Toilets, Showers, BBQ, Fire pits, Drinking water, Vehicle access
2. **Weather** — "Avoid heat (>33C)", "Avoid rain" — visually dimmed + tooltip if no eligible date selected

Chips use the existing `fern`/`ink`/`fog` token palette.

## Results Section

- Full-width (no sidebar column)
- Count + view toggle (list/map) in a results bar above the grid
- Card grid: `repeat(auto-fill, minmax(320px, 1fr))`
- Cards unchanged in content, minor visual polish:
  - Fraunces display font for site name
  - Park type badge at top
  - Drive time as a tappable Maps link
  - Weather panel (existing)
  - Facilities chips (existing)
  - Availability status (existing)

## Visual Design

### Typography
- Display: `Fraunces` (serif, existing token) — used for brand title and step headings
- Body: `Work Sans` (existing token)

### Color
- Background: warm off-white (`sand` #f2eadc) for header zone
- Chip active: `fern` #2f5e3a fill, white text
- Chip inactive: white fill, `ink/30` border, `ink` text
- Step numbers: `fern` small caps

### Header zone
- Warm `sand` background with subtle texture
- Rounded bottom corners to separate from white results zone
- Max-width 6xl, padded

### Animations
- Chips: 150ms ease transition on background/color
- Date-to input: fades in when date-from is selected
- Cards: existing hover lift
